Regras nesta versão

  1. Dois jogadores alternam no mesmo dispositivo.
  2. Ao formar uma linha de três, remova uma peça adversária.
  3. Na fase de movimento, selecione uma peça e depois uma casa vizinha.
  4. Com três peças, o jogador pode voar para qualquer casa livre.
