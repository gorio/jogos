Como jogar Dama

  1. As peças se movem uma casa na diagonal para frente.
  2. Para capturar, salte na diagonal sobre uma peça adversária para uma casa vazia.
  3. Capturas disponíveis devem ser feitas quando existirem.
  4. Ao chegar na última linha, a peça vira dama e pode andar para frente e para trás.
  5. Vence quem capturar todas as peças adversárias ou deixar o rival sem movimentos.
